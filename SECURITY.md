# Security Policy

## Reporting a vulnerability

Please report security concerns privately to `devalltect00@gmail.com`. Do not
include secrets, access tokens, or private repository data in a public issue.

Include the affected page, a concise reproduction, the expected behavior, and
the impact you observed. You will receive an acknowledgement after the report
has been reviewed.

## Scope

This repository produces a static website. Reports about dependency security,
unsafe outbound links, exposed configuration, build workflows, or deployment
integrity are in scope. General content corrections can use the normal issue
tracker.
